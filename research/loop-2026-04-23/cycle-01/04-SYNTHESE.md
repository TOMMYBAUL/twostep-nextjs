# Cycle 01 — Synthèse

## Top 3 insights

### Insight #1 — Le plafond solo Two-Step est ~40 marchands, pas 100
**Confiance 7/10.** Benchmarks SMB SaaS : 1 CSM = 200-500 clients (~2-3h/mois/compte). Pour Two-Step : avec commerçants physiques non tech-natifs + prospection continue en parallèle + produit + admin, plafond solo réaliste = **~40 marchands**. Au-delà : automation AI + délégation frère/apporteurs obligatoire. **Implication immédiate** : investir dans self-service docs + community WhatsApp AVANT d'atteindre 10 marchands, sinon dette opérationnelle violente en Phase 2.

### Insight #2 — Google LFP reste le bon canal pour intent search précis FR, **mais** la thèse "stock local" doit être adaptée par profil âge client
**Confiance 8/10.** Les 35+ (démographie majoritaire FR, âge médian 42) restent 70-79% Google pour recherche commerce local. Les <25 ans ont migré vers Instagram (67%) et TikTok (62%). **Implication** : Two-Step continue Google LFP priorité 1, mais le pitch aux boutiquiers jeunes/hip (sneakers, streetwear) doit mentionner que leurs clients jeunes passent par Insta — ajouter un argument social sans s'éparpiller dans l'intégration.

### Insight #3 — FLL auto (Free Local Listings) a peut-être supprimé le besoin d'implémenter Voie B LFP
**Confiance 6/10.** Source février 2026 : Google utiliserait automatiquement le feed Merchant API standard (Voie A) + les signaux site web pour alimenter FLL. **Si vrai**, Two-Step peut livrer de la valeur Google Shopping Local **dès le 1er marchand connecté** sans attendre l'activation Voie B par le specialist. **À tester URGEMMENT** : semaine prochaine, query "produit-de-Sole-Store Toulouse" sur Google mobile et screenshot. Si la vitrine apparaît dans FLL → Voie B n'est plus critique Phase 1.

## Impact concret sur Two-Step

### Décisions business immédiates (lundi matin potentiel)

1. **Pitch adjust** : remplacer "on rend visible votre stock" par "on met vos produits dans Google Shopping local, gratuitement, sans commission" (plus concret)
2. **Onboarding "on fait pour vous" explicite** : faire une demo chez Dear Skin Shop en disant "moi je fais le setup, vous donnez l'export CSV"
3. **Cible ajustée** : 7 marchands signés en 6 semaines (non 5, buffer pour les no-shows)
4. **Test FLL auto** cette semaine : vérifier via query Google si Sole Store seed apparaît déjà → décide la stratégie Voie B

### Décisions produit immédiates

1. **Reporter implémentation Voie B** jusqu'à test FLL auto concluant ou confirmation specialist
2. **Ajouter check GBP à l'onboarding marchand** (Google Business Profile vérifié + lié Merchant Center)
3. **Bootstrap community features dès 5 marchands** : WhatsApp groupe Saint-Étienne, docs Loom onboarding, FAQ
4. **Pas de chantier social commerce Phase 1** (TikTok Shop, Insta Shopping) — focus Google

### Risques structurels à surveiller

1. **Burnout Thomas à 30-40 marchands** si pas d'automation CS — surveiller signes dès Phase 1
2. **Dette prospection saisonnalité été** — potentiellement valider en calendrier Phase 1
3. **Dépendance Google LFP** : si Google ralentit la review (8-12 semaines), le plan Phase 1 Trusted à 3 mois glisse
